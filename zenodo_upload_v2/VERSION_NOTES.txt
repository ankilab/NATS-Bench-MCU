Outcome taxonomy corrected: failures now carry a single, well-defined "infeasible"

HOW TO USE THIS VERSION
-----------------------
Most users — the tabular data:
  Download and extract export.tar.gz. The CSVs already reflect every correction; there
  is nothing to merge. Start from export/README.md.

Working from the raw per-architecture artifacts:
  The 16 artifacts_*.tar.gz archives are the unchanged v1 measurements. The 117 corrected
  records live in the new corrections.tar.gz overlay. Extract the archives and the overlay
  side by side, then merge them into one fully corrected artifacts/ tree with:

      python corrections/apply_corrections.py            # merges overlay -> artifacts/
      python corrections/apply_corrections.py --dry-run  # preview the changes first

  The merge is idempotent and preserves each architecture's original INT8 model file.
  See corrections/README.md for full provenance and the per-architecture rationale.
